# OCA-77: wrap text using its font

Selected 2026-10-29 after OCA-42's compiled string-table recipe. OCA-41 and
OCA-42 retain their separate wasm, authored-atlas and browser qualification
gates. Those gates do not prevent an independent metadata-only text query.
The existing L21 story asks for an engine operation beside measurement;
OCA-43 already states which scripts the glyph walk supports.

## Scope and contract

Add `Font::wrap` and the handle-based `RenderResources::wrap_text` query.
They return owned wide text measured with the same glyph placement as
`Font::measure`. The game chooses the available unscaled font width and
wraps when text changes, outside drawing. Widget positions, translation,
editing and automatic layout remain game decisions.

Use a finite positive width. Replace selected U+0020 spaces with U+000A
line feeds; preserve every other code unit, existing CR/LF and unselected
spaces. Do not trim or collapse whitespace, hyphenate or split a word.
An unbroken word may exceed the width. Scripts without spaces need a
game-owned language-specific break policy; this operation supplies none.
Visible leading, trailing or repeated spaces can become empty lines rather
than being silently discarded. Exact fits remain on their current line.

Keep fallback lookup and missing-glyph errors consistent with measurement.
The returned string owns its storage, accepts a length-aware view including
embedded NULs and retains no input view. The resource query validates its
font handle even for empty text. Neither query creates a device or draws.

## Implementation and verification plan

Share the existing glyph step with the new operation while preserving its
floating-point order, bearing accumulation, zero clamp, blank suppression,
callback-before-advance ordering and temporary callback position. The public
walker still takes its action by value once; continuation passes it by
reference so mutable and move-only actions retain their existing behavior.

Track the maximum emitted glyph-right edge, rather than the final pen.
On overflow, break at the latest space and replay only the suffix after it
from a new origin. That suffix has no space, so replay intervals are
disjoint and each input unit is visited at most twice. Binary glyph lookup
makes the total bound O(n * (1 + log(g + 1))) for n units and g glyphs;
the owned output is O(n) and walk state is constant. Do not add a timing
threshold or claim that a large-output test proves this complexity bound.

Behavioral tests use synthetic Font metadata: exact fits, existing
lines, visible and invisible spaces, bearings and clamping, negative
advances, overlong words, unspaced text, fallback, bad widths, bounded views,
owned results, resource forwarding and callback semantics. No glyph image
or graphics API device is required for those cases.

Build and run only the source-inventoried headless `RenderTests` target in
the five native Debug render configurations and Release null, with build
parallelism two and test parallelism one. Check existing installed-cache
guards first. Run the eight standalone checks and website check, tests and
build; verify both published API contracts and the guide in generated HTML.

## Recorded source and native checks

The two queries, shared private glyph step, guide and fifteen new cases
are implemented. Six original source hashes, frozen candidate hashes and
58 named boundary-source hashes were checked before applying the changes.
An independent review approved the same candidates. Exact reversal of the
private extraction preserves the previous glyph arithmetic; the existing
measurement implementation and existing test bodies are unchanged. New
C++ uses ASCII escapes, retaining the owner's raw source-literal reservation.

The thirteen font cases cover the documented wrap policies, measured line
widths, peak ink with a retreating pen, replay from a clamped origin, owned
and bounded text, fallback and invalid widths. Two resource cases exercise
handle validation, bounded forwarding and font replacement in a stable slot.
The public walker also retains one action copy for an lvalue, mutable
move-only callbacks, a temporary position that cannot mutate its cursor,
and the grouped floating-point advance at a rounding boundary.
