Each guide takes one job and shows how a sample in the repository does it, quoting the sample's
code as it is at the revision this site was built from. Where the samples do not cover part of a job,
the guide says so. The quoted code is in the engine's `samples` folder, not in your game. In a
starter project that is `C:\dev\mygame\external\labrador\samples`, and
[Run the samples](/docs/guides/samples/) builds and starts them from there. They assume the model described in [Concepts](/docs/concepts/). When a build fails after you
change your game, [Read a build error](/docs/get-started/build-errors/) shows how to find the line that matters.
