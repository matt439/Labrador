## What you need to know already

Some C++, and how to use a command prompt. The guide explains every command it asks you to
type, but it does not teach the language.

## What it was checked against

Every command on these pages was run on Windows 11 with Visual Studio's x64 Native Tools
Command Prompt, against the revision of Labrador shown at the bottom of each page. The project
in step 4 was built from the public repository exactly as the page describes. If a step does not
do what the page says, that is a bug in the page:
[report it](https://github.com/matt439/Labrador/issues).
