These pages explain how Labrador sees a game: what it calls, what it owns, what it leaves to you,
and in what order things happen. They assume you have
[built and run the minimal sample](/docs/get-started/run-minimal/), and they point at its code
throughout, so having it open helps.

Each idea here also appears in the [design documents](/docs/design/), which give the reasons in
full. The pages below give enough of the reasons to use the engine well, and link to the rest.
