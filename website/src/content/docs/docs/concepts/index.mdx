These pages explain how Labrador sees a game: what it calls, what it owns, what it leaves to you,
and in what order things happen. Each page quotes the sample code it discusses, so they read
without a build, on any machine. To see a game on the engine run without building anything,
[play LineSweeper in a desktop browser](https://mattharding.dev/demo/linesweeper/), the one
sample hosted today. Building the minimal sample by [Get Started](/docs/get-started/) is
optional, though having its code open beside these pages helps.

Each idea here also appears in the [design documents](/docs/design/), which give the reasons in
full. The pages below give enough of the reasons to use the engine well, and link to the rest.
