LineSweeper

LineSweeper has touch controls, but no real phone has played it yet, so for now this page asks for a keyboard or a controller.

Arrows move, Up or X rotates, Space drops, C holds, Escape pauses.

Accessibility: Keyboard play is supported; controller input is implemented but physical-controller checks are pending. Tab moves focus out of the game. Controls are fixed, and screen readers cannot read the game state. Touch play is held back pending real iPhone and phone-layout checks. The landing shadow stands out from the empty well for every piece. A browser set to reduce motion gets line clears and a top-out with an eighth of the sparks. The pause menu's COLOURS row offers piece palettes for protanomaly / protanopia, deuteranomaly / deuteranopia and tritanomaly / tritanopia; they were chosen by simulation and have not yet been checked by players. The choice is not saved.

A falling-block game and a sample for Labrador, a 2D game engine in C++, compiled to WebAssembly and drawn with WebGL2. Third-party notices.
