LineSweeper in a browser - notices

linesweeper.wasm and linesweeper.js are LineSweeper, a sample game for the
Labrador engine (https://github.com/matt439/Labrador), compiled to WebAssembly
with Emscripten. Labrador and LineSweeper are MIT licensed. The module also
contains code and content that are not Labrador's, statically linked or
embedded at build time, and each is listed here with its licence. BUILD.json
beside this file names the Labrador commit and the Emscripten version the
module was built from.
